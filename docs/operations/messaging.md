# راهنمای عملیات پیام‌رسانی (Messaging Operations)

## ۱. تنظیمات (Configuration)
تنظیمات پیام‌رسانی (پیامک و ایمیل) به صورت متمرکز در منوی **Carmilla -> Integrations** در پنل مدیریت وردپرس انجام می‌شود.
این تنظیمات شامل درگاه پیامک (Generic HTTP)، اطلاعات SMTP برای ایمیل، و قالب‌های پیام (Templates) می‌باشد.
تمامی رمزها و کلیدهای API (نظیر `sms_api_key` و `smtp_pass`) در پایگاه‌داده به صورت رمزنگاری‌شده (Encrypted) ذخیره می‌شوند.

## ۲. چرخش کلیدها (Key Rotation)
جهت تعویض کلیدها یا رمزهای عبور (Rotation):
1. به پنل ارائه‌دهنده سرویس (Provider) مراجعه و کلید جدید بسازید.
2. به بخش **Carmilla -> Integrations** بروید.
3. کلید جدید را در فیلد مربوطه وارد و ذخیره کنید.
4. رمزنگاری بلافاصله با کلید جدید انجام می‌شود.
*توجه: در صورت تغییر `CARMILLA_SECRET_KEY` در فایل `wp-config.php`، باید کلیدهای API را مجدداً وارد و ذخیره کنید.*

## ۳. خطایابی (Troubleshooting)
- **عدم ارسال پیامک:** از تب Test یک پیامک آزمایشی ارسال کنید. خطاها با جزئیات در فایل `debug.log` ثبت می‌شوند (لاگ‌ها PII و شماره کامل را پنهان می‌کنند مثلاً `091***99`).
- **خطای SSL/HTTPS:** در صورت اجبار HTTPS برای درگاه پیامک، آدرس HTTP رد خواهد شد. مطمئن شوید آدرس درگاه با `https://` شروع می‌شود.
- **ایمیل‌های ارسالی اسپم می‌شوند:** تنظیمات `From Email` و `From Name` را بررسی کنید. همچنین فعال بودن SMTP Auth و استفاده از TLS پورت ۵۸۷ پیشنهاد می‌شود.

## ۴. افشای داده (Data Disclosure)
- **داده‌های ارسالی:** پلتفرم برای پیامک تنها "شماره موبایل" و "متن پیام" را به ارائه‌دهنده ارسال می‌کند. هیچ اطلاعات شخصی دیگری (PII/PHI) منتقل نمی‌شود.
- **ایمیل:** در ایمیل‌ها آدرس گیرنده، عنوان و متن ایمیل ارسال می‌شود.
- پلتفرم کاملاً نسبت به ارائه‌دهنده خنثی (Vendor-neutral) است و وابستگی مستقیم به SDK خاصی ندارد.
