# P01-SECURITY-CODE-005C — تصمیم انتقال QA HTTPS

- تاریخ: ۲۰۲۶-۱۰-۲۸
- تصمیم‌گیر: مالک پروژه
- تصمیم: آزمون دستی Web session-cookie که به HTTPS معتبر نیاز دارد، به `P10-RELEASE-SEC-021` منتقل شد.
- علت: محیط توسعهٔ محلی مالک دسترسی HTTPS لازم را ندارد.
- اثر: هیچ ادعای PASS برای cookie `Secure`،rotation یا logout در HTTPS از این مدرک برداشت نمی‌شود؛ این موارد در Gate انتشار فاز ۱۰ باز هستند.
