- **ارجاع جایگزین:** این ادعای تأییدنشده باید در سناریوی QA جایگزین **P03-QA-MANUAL-027** دوباره بررسی و تأیید انسانی شود. وضعیت DONE گذشته بدون تأییدیه، مجوز Gate جدید نیست.
