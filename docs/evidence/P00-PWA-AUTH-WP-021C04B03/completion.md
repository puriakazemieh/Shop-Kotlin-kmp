# Supported identity primitive completion

Date: 2026-10-20

The split feasibility work is complete only for Carmilla's supported writers. The
evidence chain covers user creation, guarded mutation, mobile metadata, concurrent
claims, fault paths, post-callback verification and the separate fail-closed managed
deletion flow on disposable WordPress/MariaDB fixtures.

This is deliberately not a claim that arbitrary WordPress, raw SQL or third-party
writes obey the primitive. Those writers require the next collision-aware reversible
synthetic migration and its owner review. Browser registration QA remains a separate
owner-controlled card.
