# P01-SECURITY-ADR-030 — تصمیم ماندگاری امن نشست Native

- تاریخ: ۲۰۲۶-۱۰-۲۸
- تصمیم‌گیر: مالک پروژه
- تصمیم: Desktop و Android نباید با هر restart کاربر را logout کنند؛ persistence فقط از طریق vault امن سیستم‌عامل مجاز است.
- وضعیت Android: کد موجود `EncryptedSharedPreferences` با `Android Keystore` دارد؛ validation دستگاه و backup در `P11-ANDROID-SEC-007` باقی است.
- وضعیت Desktop: fallback فعلی فقط حافظه است و عمداً persistence ناامن ندارد؛ vault بومی در `P17-DESKTOP-SEC-005` پیاده‌سازی و آزموده می‌شود.
- اثر: هیچ token واقعی یا secret در این Evidence ثبت نشده است.
