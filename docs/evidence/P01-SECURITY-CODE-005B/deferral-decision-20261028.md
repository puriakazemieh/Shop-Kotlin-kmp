# P01-SECURITY-CODE-005B — تصمیم انتقال scope

- تاریخ: ۲۰۲۶-۱۰-۲۸
- تصمیم‌گیر: مالک پروژه
- تصمیم: کار Keychain iOS از فاز ۰۱ خارج و به `P16-IOS-SEC-006` منتقل شد.
- وضعیت فنی هنگام انتقال: هیچ Evidence معتبر برای مهاجرت `NSUserDefaultsSettings` به Keychain وجود ندارد.
- اثر: این مدرک تنها پایان scope فاز ۰۱ را ثبت می‌کند؛ امنیت token در iOS تا انجام و پذیرش `P16-IOS-SEC-006` باز است.
