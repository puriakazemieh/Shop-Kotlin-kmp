## Public Licensing Rules
1. **Gate Prerequisite:** A capability or target platform is advertised as "Production Ready" ONLY after passing its specific phase Gate (e.g. `P04-WORDPRESS-GATE-037`, `P08-PWA-GATE-019`).
2. **Feature vs License Boundary:** Possessing the source code binary in a ZIP does not constitute a license. Capability is enabled only when (Feature Code Present) AND (Site Entitlement Valid) AND (Manager Toggle Enabled).
