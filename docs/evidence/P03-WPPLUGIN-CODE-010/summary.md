# شواهد P03-WPPLUGIN-CODE-010

تاریخ: ۲۰۲۶-۰۸-۲۶

## نتیجه

- صفحهٔ «Carmilla Manifest» در Settings وردپرس برای مدیر سایت افزوده شد.
- هر ذخیره‌سازی از مسیر سرور، وابستگی featureها را بررسی می‌کند؛ در صورت نامعتبر بودن، option اصلی تغییر نمی‌کند و رویداد `manifest_update_rejected` در `cb_manifest_audit_log` ثبت می‌شود.
- ذخیرهٔ معتبر نیز رویداد `manifest_updated` را بدون secret یا دادهٔ مشتری ثبت می‌کند.
- تست smoke، حالت فرزندِ فعال با والد غیرفعال و حالت معتبر را پوشش می‌دهد.

## تست‌های خودکار

- PHP lint برای `class-cb-manifest-controller.php`: موفق
- PHP lint برای `class-cb-plugin.php`: موفق
- `tests/smoke-manifest.php`: موفق

## تست دستیِ منتقل‌شده

به درخواست کاربر، نصب افزونه و کنترل UI در wp-admin انجام نشد و باید همراه `P03-QA-MANUAL-020` در پایان فاز ۳ انجام شود. معیار: ذخیرهٔ ترکیب نامعتبر باید رد شود، مقدار قبلی manifest باقی بماند و یک رکورد ممیزی بدون دادهٔ حساس ایجاد شود.
