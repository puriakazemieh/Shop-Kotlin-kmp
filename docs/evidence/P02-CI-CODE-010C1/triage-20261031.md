Standard WordPress normally defines `SECURE_AUTH_KEY`, so the default path is conditional; nevertheless, if reached it encrypts provider credentials under a public fixed key. Do **not** waive this as a Theme Check base64 style warning. The code needs a fail-closed key policy and compatibility/rotation plan. This is outside 010C's allowed CI/tools/docs paths.

A crash or write error can leave readable content on disk; the uploads directory may be web reachable depending on site configuration.
