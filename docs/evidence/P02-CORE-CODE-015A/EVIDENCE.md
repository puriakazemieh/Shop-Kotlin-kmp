# مستندات اثبات (Evidence) برای P02-CORE-CODE-015A

## اهداف و اقدامات
تسک P02-CORE-CODE-015A برای اضافه کردن تست معماری جهت جلوگیری از افزودن وابستگی‌های معکوس و متقابل بین ماژول‌های Feature ایجاد شد.
یک اسکریپت سفارشی Gradle با عنوان `architecture-check.gradle.kts` ساخته و در `build.gradle.kts` اصلی ثبت شد.
این اسکریپت وابستگی‌های تمامی پروژه‌های `:feature:*` را بررسی کرده و در صورت وجود وابستگی به یک پروژه `:feature:*` دیگر، بیلد را متوقف می‌کند (Fail).

استثناهای مجاز موقت (برای حفظ کامپایل تا زمان ریفکتور در 015B) به اسکریپت اضافه شدند تا وضعیت فعلی مسدودکننده توسعه نباشد.

## وضعیت بیلد و اعتبارسنجی
اجرای دستور `./gradlew.bat architectureCheck` با موفقیت پایان یافت (وضعیت سبز با خروجی لیست موارد Allowed). این بدین معناست که ساختار کنترل معماری به‌درستی کار می‌کند.
