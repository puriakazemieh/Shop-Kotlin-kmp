# راه‌اندازیِ سایتِ واقعی (kazemieh.com) — چک‌لیستِ گام‌به‌گام

> فازهای ۲ و ۳ و ۵ از `PATH_AB_COMPLETION_PLAN.md`. این مراحل به wp-admin و
> کلیدهای شما نیاز دارند و از CI قابلِ انجام نیستند. هر گام مستقل است؛ به‌ترتیب بروید.

## فاز ۲ — پوسته و پلاگین روی سایت

1. **پوسته:** «نمایش → پوسته‌ها → بارگذاری» → فایلِ `wordpress/carmilla-theme.zip`
   (نسخه‌ی **0.7.8**، از ریپو یا آرتیفکتِ Build All) → نصب و **فعال‌سازی**.
   اگر نسخه‌ی قدیمی نصب است، اول حذفش کنید تا فایل‌های تازه جایگزین شوند.
2. **پلاگین:** «افزونه‌ها → افزودن → بارگذاری» → `wordpress/carmilla-bridge.zip`
   (0.7.2) → نصب و فعال‌سازی. WooCommerce هم باید نصب/فعال باشد.
3. **خانه‌ی Elementor را کنار بگذارید (علتِ اصلیِ «شبیه نشدن» سایتِ فعلی):**
   «تنظیمات → خواندن»؛ اگر «صفحه‌ی ثابت» روی صفحه‌ای با قالبِ Elementor Canvas
   است (page-id-206)، یا حالت را روی «آخرین نوشته‌ها» بگذارید یا صفحه‌ی ثابتِ
   دیگری بدونِ قالبِ Canvas انتخاب کنید — تا `front-page.php` پوسته فعال شود.
4. **پیوندهای یکتا:** «تنظیمات → پیوندهای یکتا» → «نامِ نوشته» + ذخیره.
   (بدونِ این، `/wp-json/` و در نتیجه اپ کار نمی‌کند.)
5. **محتوا:** یا «ابزارها → دموی کارمیلا» (واردکنِ نمونه‌ی خودِ پوسته) یا
   محصولات/نوشته‌های واقعیِ خودتان.
6. **تست:** خانه/فروشگاه/محصول را باز کنید — باید مثلِ اسکرین‌شات‌های
   `claude/ci-screenshots` باشد. سپس `https://kazemieh.com/wp-json/carmilla/v1/api/products`
   را باز کنید — باید JSON برگردد (نه ۴۰۴).

## اتصالِ اپ به سایت

- **اندروید:** Actions → **Build All** → flavor=`wp` و
  `base_url=https://kazemieh.com/wp-json/carmilla/v1/` → APK خروجی مستقیم به
  سایتِ شما وصل است (پلاگینِ وردپرس هم به‌عنوانِ آرتیفکت همان‌جا خروجی می‌آید).
- **وب:** خروجیِ `web-dist` را هر جا هاست کنید و با
  `/?api=https://kazemieh.com/wp-json/carmilla/v1/` باز کنید (برندِ wp خودکار
  انتخاب می‌شود)؛ یا Actions → **Deploy Web** با همان `api_base`.

## فاز ۳ — تجارتِ کامل (WooCommerce + ZarinPal)

1. WooCommerce → تنظیمات: واحدِ پول **تومان**، کشور ایران، نرخ/حمل‌ونقلِ دلخواه.
2. محصولاتِ دوره/تست/نوبت را **Virtual** علامت بزنید (بدونِ حمل‌ونقل).
3. مرچنتِ ZarinPal: «تنظیمات → Carmilla Bridge» (یا optionهای پلاگین) —
   ابتدا سندباکس، بعد مرچنتِ واقعی.
4. یک خریدِ آزمایشیِ کامل انجام دهید: افزودن به سبد → تسویه → درگاه → بازگشت.
   برای محصولِ دیجیتال چک کنید دسترسی (ثبت‌نامِ دوره/تست) خودکار فعال شود.

## فاز ۵ — استقرارِ دائمیِ سرورِ Spring (اختیاری، اگر مسیرِ سرورِ خودی را هم می‌خواهید)

- ریپوی سرور `Dockerfile` و `liara.json` دارد → روی **Liara** (ایرانی) یا
  Render/Railway دیپلوی کنید + PostgreSQL مدیریت‌شده + بکاپِ روزانه.
- متغیرها: `DATASOURCE_URL/USERNAME/PASSWORD`, `JWT_SECRET_KEY`,
  `ZARINPAL_MERCHANT_ID`, `APP_CORS_ORIGINS=<دامنه‌ی وب>`, `SEED_ENABLED=false`.
- سپس APK با `base_url=https://<دامنه‌ی سرور>/` بگیرید.
- **iOS نصب‌شدنی:** به Certificate + Provisioning حساب Apple Developer نیاز دارد؛
  هر وقت داشتید، job امضادار به CI اضافه می‌کنیم.
