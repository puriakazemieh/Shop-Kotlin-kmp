# Task: P04-WPTHEME-CODE-025 - بررسی و رفع مشکل نمایش صفحات با قالب المنتور

## Prompt اولیه برای AI
```text
هدف: بررسی و رفع مشکل عدم نمایش صحیح صفحات زمانی که از قالب (Template) المنتور استفاده می‌شود.

پیش‌زمینه:
در تست اکتشافی Baseline (P00-QA-MANUAL-018) مشخص شد که اگر برگه با ویژگی قالب المنتور (Elementor Template) باشد، صفحه به درستی نمایش داده نمی‌شود و حتماً باید روی قالب کارمیلا (Carmilla Theme) باشد.

اقدامات مورد نیاز:
1. بررسی نحوه هندل کردن Template Hierarchy در پوسته carmilla-theme.
2. بررسی تداخل احتمالی بین carmilla-bridge و Elementor.
3. اطمینان از اینکه اگر کاربری بخواهد از Elementor Canvas یا Elementor Full Width استفاده کند، پوسته مانع نمایش محتوا نشود.
4. اصلاح کد در پوسته یا افزونه برای پشتیبانی از قالب‌های المنتور در کنار قالب اختصاصی کارمیلا.

معیار پذیرش:
- یک برگه جدید با قالب Elementor Canvas ایجاد شود و محتوای آن به درستی نمایش داده شود.
- یک برگه جدید با قالب Elementor Full Width ایجاد شود و Header/Footer کارمیلا در کنار محتوای المنتور به درستی کار کند.
- هیچ کرش یا خطای PHP در لاگ‌ها مشاهده نشود.
```
