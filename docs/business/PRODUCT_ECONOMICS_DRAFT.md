## 3. Support Scope & SLA
- **XS Issues (Bug fixes)**: 48h Response
- **S Issues (Config assistance)**: 72h Response
- **Customization**: Out of Scope (Requires separate quote)

## 4. Refund Taxonomy
- **Technical Failure**: Full refund if Carmilla fails to run on supported stack.
- **Change of Mind**: Partial refund (minus marketplace fee) within 7 days (if no build was delivered).
- **Service SKU**: Non-refundable once build process begins.
