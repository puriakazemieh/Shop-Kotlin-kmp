# صف اجرای Taskهای Carmilla

## Prompt اولیه برای AI

```text
این فایل فقط صف اجرای Taskها است. دقیقاً یک Task را در هر نوبت انجام بده.
1. اولین ردیف READY را پیدا کن.
2. اگر READY وجود ندارد،Task دلخواه از TODO انتخاب نکن؛dependencyها و آخرین Task را بررسی و Blocker را گزارش کن.
3. فایل docs/tasks/<TASK-ID>.md را کامل بخوان؛Prompt ابتدای همان کارت مرجع اجرا است.
4. فقط همان کارت را اجرا کن. بدون Evidence یا تست دستی انسانی،Master checklist را DONE نکن.
5. اگر اقدام انسانی/خارجی لازم است،مراحل دقیق،محیط،داده و انتظار را به کاربر بگو و Status را AWAITING_MANUAL_QA یا BLOCKED بگذار.
6. پس از تکمیل واقعی،فقط row همین Task و Completion record کارت را به‌روزرسانی کن؛سپس اگر dependency پاس است،Task بعدی را READY کن.
7. به Task بعدی نرو و تغییرات کاربر را حفظ کن.
```

## وضعیت‌ها

- READY: تنها Task مجاز برای شروع AI.
- TODO: dependency یا تصمیم لازم هنوز آماده نیست.
- CODE_COMPLETE: کد/تست خودکار انجام شده،اما تست دستی یا Review باقی است.
- AWAITING_MANUAL_QA: AI باید مراحل دستی را به کاربر بدهد.
- DONE: فقط پس از Evidence و authority لازم؛آن‌وقت checkbox Master هم تیک می‌خورد.
- BLOCKED: دلیل،Evidence و اقدام لازم برای رفع blocker ثبت شود.
