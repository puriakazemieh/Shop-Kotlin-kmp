A modern token-based Persian/RTL commercial theme for WordPress and WooCommerce, mirroring the Compose Multiplatform client design system.

== Description ==

Carmilla is an independent commercial WordPress theme providing dedicated verticals for e-commerce, blog, academy, and clinic booking. Designed with a custom token architecture inspired by Jetpack Compose Multiplatform.

== Installation ==

1. In wp-admin, navigate to Appearance → Themes → Add New → Upload Theme.
2. Select carmilla-theme.zip and click Install Now.
3. Activate Carmilla.

== Frequently Asked Questions ==

= Does this theme work independently of Carmilla Bridge? =
Yes. Carmilla Theme bundles carmilla-core and operates as a standalone product.
